# Support

Use [GitHub Discussions](https://github.com/newtonlorenz/longchat-proxy/discussions) for setup,
configuration and usage questions. Use the issue templates for reproducible bugs and focused
feature requests.

Before asking for help:

1. run `longchat-proxy doctor`;
2. run `longchat-proxy print-config` and remove identifying paths;
3. check the README's failure behaviour and provider-specific settings;
4. reproduce with the smallest non-private conversation possible.

Never post API keys, private conversations, public IP addresses, model weights, `.env` files or
SQLite state. Report security problems through the repository's private security advisory form.

Community support is best-effort; no response time or compatibility guarantee is offered.
